
# 🍳 AI-Шеф: Чат-бот для поваров ВКонтакте

Этот проект представляет собой умного чат-бота для социальной сети ВКонтакте, созданного специально для ресторанных поваров. Бот интегрирован с бесплатной российской нейросетью **GigaChat** (от Сбера). 

Повара могут писать боту в личные сообщения сообщества, задавать любые кулинарные вопросы (например, «Предложи три новых соуса к курице» или «Как разнообразить подачу салата Цезарь?»), а нейросеть будет выдавать структурированные рецепты и идеи для меню.

## 🌟 Возможности

*   **Работа в реальном времени:** Бот использует `LongPoll API` ВКонтакте, поэтому отвечает мгновенно (не требует наличия публичного сервера или домена).
*   **Полностью бесплатно:** Использует щедрый Freemium-лимит GigaChat (365 млн токенов в год для физлиц).
*   **Роль Шеф-повара:** Встроенный системный промпт (System Prompt) заставляет нейросеть отвечать кратко, профессионально и строго по кулинарной теме.
*   **Безопасность:** Все токены и ключи хранятся в отдельном файле `.env`, а не в исходном коде.

## 🛠️ Технологии

*   **Язык:** Python 3.8+
*   **Библиотеки:** `vk_api`, `requests`, `python-dotenv`
*   **API:** VK LongPoll API, GigaChat API

## 🚀 Пошаговая инструкция по установке

### Шаг 1. Подготовка окружения
Убедитесь, что у вас установлен Python. Откройте терминал (командную строку) в папке с проектом и установите необходимые библиотеки:
```bash
pip install vk_api requests python-dotenv
```

### Шаг 2. Настройка сообщества ВКонтакте
1. Создайте новое сообщество ВК (или используйте существующее).
2. Перейдите в **Управление** ➔ **Работа с API**.
3. Нажмите **Создать ключ**. Выберите права: «Сообщения сообщества» и «Управление сообществом». Скопируйте этот токен (он понадобится ниже).
4. Перейдите во вкладку **Long Poll API** ➔ Включите его.
5. В настройках Long Poll (Типы событий) поставьте галочку напротив **«Входящее сообщение»**.
6. Перейдите в **Управление** ➔ **Сообщения** ➔ **Настройки для бота**: включите «Возможности ботов».
7. Узнайте **ID вашего сообщества** (цифры из адресной строки `vk.com/club123456789` или в разделе «Основная информация»).

### Шаг 3. Получение ключа GigaChat
1. Зайдите на портал [developers.sber.ru](https://developers.sber.ru/) через Сбер ID.
2. Создайте новый проект **GigaChat API**.
3. В настройках проекта сгенерируйте **Ключ авторизации** (Authorization key). Скопируйте его.

### Шаг 4. Настройка файла `.env`
В корневой папке проекта создайте файл с именем ровно `.env` (без расширения `.txt`). Вставьте туда ваши ключи строго в таком формате (без пробелов вокруг `=` и без кавычек):

```env
VK_TOKEN=ваш_токен_из_шага_2
GIGACHAT_AUTH_KEY=ваш_ключ_из_шага_3
VK_GROUP_ID=123456789
```
*(Где `123456789` — это ID вашего сообщества).*

## 🏃‍♂️ Запуск бота

Запустите скрипт через терминал:
```bash
python bot.py
```

Если вы увидели сообщение `Бот запущен и слушает сообщения...`, значит всё работает. Теперь повара могут открыть страницу вашего сообщества ВК, нажать «Написать сообщение» и задать вопрос. Бот ответит в течение 5–15 секунд.

## ⚠️ Решение частых проблем (Troubleshooting)

1. **Ошибка `[AI ERROR] 404 Client Error`**
   *   *Причина:* Устарел адрес API или неверное название модели.
   *   *Решение:* В коде бота должно быть `API_URL = "https://api.giga.chat/v1/chat/completions"` и модель `GIGACHAT_MODEL = "GigaChat-3-Ultra"`.

2. **Ошибка `AttributeError: 'dict' object has no attribute 'from_id'`**
   *   *Причина:* Библиотека ВК передает данные в виде словаря.
   *   *Решение:* Обращаться к элементам нужно через квадратные скобки: `message['from_id']` и `message['text']`.

3. **Кракозябры в консоли Windows (`��� �������...`)**
   *   *Причина:* Кодировка консоли.
   *   *Решение:* В начале файла `bot.py` добавьте:
       ```python
       import sys
       sys.stdout.reconfigure(encoding='utf-8')
       ```

4. **VS Code подчеркивает `import requests` желтым**
   *   *Причина:* VS Code (Pylance) использует другой интерпретатор Python.
   *   *Решение:* Нажмите `Ctrl+Shift+P` ➔ `Python: Select Interpreter` ➔ выберите ваш установленный Python. Или просто проигнорируйте, если в терминале бот запускается.

5. **Предупреждения `InsecureRequestWarning`**
   *   Это связано с тем, что запросы к Сберу идут с `verify=False` (из-за особенностей сертификатов Минцифры). Чтобы убрать шум в консоли, в коде добавлен блок `urllib3.disable_warnings()`.

## 🔒 ВАЖНО: Безопасность токенов

Файл `.env` содержит ваши пароли и ключи доступа. 
* **Никогда не выкладывайте файл `.env` в открытый доступ** (на GitHub, форумы или в чаты).
* Если вы случайно показали ключи кому-то, **немедленно перевыпустите их**:
  * Для ВК: Удалите старый ключ в настройках сообщества и создайте новый.
  * Для GigaChat: Сгенерируйте новый Ключ авторизации в личном кабинете Сбера.
